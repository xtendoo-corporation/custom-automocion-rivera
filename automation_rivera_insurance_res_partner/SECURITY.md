## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en este módulo, por favor repórtala de forma responsable:

1. **NO** abras un issue público en GitHub
2. Envía un email a: security@xtendoo.es
3. Incluye:
   - Descripción detallada de la vulnerabilidad
   - Pasos para reproducirla
   - Versión afectada
   - Impacto potencial
   - Si es posible, una solución propuesta

## Tiempo de Respuesta

- **Reconocimiento inicial**: 48 horas
- **Análisis y evaluación**: 7 días
- **Corrección**: Según gravedad (crítico: 24-48h, alto: 1 semana, medio: 2 semanas)

## Buenas Prácticas

Este módulo sigue las siguientes prácticas de seguridad:

- ✅ Control de acceso mediante grupos de seguridad de Odoo
- ✅ Validación de permisos en modelos
- ✅ Sin ejecución de código arbitrario
- ✅ Sin almacenamiento de datos sensibles sin cifrar
- ✅ Cumplimiento de estándares OCA

## Actualizaciones de Seguridad

Las actualizaciones de seguridad se publican:
- En el changelog del módulo
- Como nuevas versiones en GitHub
- Con notificación a usuarios conocidos

Para mantenerte informado:
- Suscríbete a las releases de GitHub
- Sigue las actualizaciones en https://www.xtendoo.es
